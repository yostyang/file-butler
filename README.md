# 文件管家（File Butler）

一个原生的 macOS 双栏文件管理器，灵感来自 Path Finder。纯 Swift / SwiftUI + AppKit 编写，无第三方依赖，支持 Apple 芯片和 Intel，macOS 13 及以上。

## 功能（v0.1 核心版）

- **双栏浏览**：左右两栏各自独立导航，可一键切换单栏 / 双栏；Tab 键在两栏间切换，F5 / F6 拷贝或移动到另一栏
- **多标签页**：每栏都可以开多个标签页，各自有独立的前进 / 后退历史
- **高性能文件列表**：基于 AppKit 原生表格，上万个文件也不卡；名称、修改日期、大小、种类四列，点击表头排序，支持多选和键入名称快速定位
- **路径栏**：面包屑可点击跳转，⌘L / ⇧⌘G 直接输入路径（支持 `~`）
- **显示隐藏文件**：⇧⌘. 一键切换
- **文件操作**：新建文件夹、重命名、拷贝 / 剪切 / 粘贴、制作副本、移到废纸篓；全部支持撤销（⌘Z）。**删除一律进废纸篓，绝不直接永久删除**
- **拖放**：两栏之间、与访达之间都能拖；同一磁盘内默认移动，跨磁盘默认拷贝，按住 Option 强制拷贝
- **右键菜单**：打开、打开方式、快速查看、在访达中显示、拷贝路径、重命名、制作副本、移到废纸篓、显示简介等
- **侧边栏**：个人收藏、自定义书签、最近访问（15 个）、已挂载磁盘及可用空间
- **快速查看**：空格键预览；可选右侧信息面板，显示缩略图、大小、日期、权限、路径
- **空间分析**：递归统计文件夹大小，环形图 + 按大小排序的列表，可逐层下钻，直接在里面定位或移到废纸篓
- **状态栏**：项目数、已选数量及大小、磁盘可用空间
- 记住每栏打开的标签页和路径，浅色 / 深色模式都适配

## 安装

1. 下载 `文件管家.dmg`，打开后把「文件管家」拖进「应用程序」。
2. 首次打开如果提示「无法验证开发者」：打开 **系统设置 › 隐私与安全性**，在页面下方点 **仍要打开**。
   也可以在终端执行：
   ```bash
   xattr -dr com.apple.quarantine /Applications/文件管家.app
   ```
3. 想浏览受保护的系统位置（例如「邮件」「信息」的数据目录），需要在 **系统设置 › 隐私与安全性 › 完全磁盘访问权限** 中打开「文件管家」。

## 从源码构建

需要安装 Xcode（或 Command Line Tools）：

```bash
./build.sh
```

会生成通用版 `build/文件管家.app` 和安装包 `build/文件管家.dmg`。图标由 `swift icon.swift` 生成 `icon.png`，再用 `sips` + `iconutil` 转成 `AppIcon.icns`。

## 已知限制

- 无法接管桌面，也不能替换系统的打开 / 保存对话框
- 不支持第三方访达扩展（如网盘同步状态图标）
- 列表中文件夹大小显示为「--」，请用空间分析查看
