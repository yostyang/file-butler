# 文件管家（File Butler）

🌐 介绍页：https://yostyang.github.io/file-butler/

一个原生的 macOS 双栏文件管理器，灵感来自 Path Finder。纯 Swift / SwiftUI + AppKit 编写，无第三方依赖，支持 Apple 芯片和 Intel，macOS 13 及以上。

## v0.3 性能优化

- 读取 1 万个文件的文件夹：约 1.5 秒 → 约 0.27 秒；每次读取多占的内存约 14 MB → 约 5 MB
- 「种类」按文件类型缓存，普通文件图标按扩展名共用，不再逐个文件读取
- 缩略图缓存有上限（约 48 MB），系统内存吃紧时自动清空；滚出屏幕的缩略图请求会取消；文件夹不生成缩略图
- 排序在后台完成；分组结果和选择索引按版本缓存，点选文件不再重新分组
- 文件操作后只刷新正在显示的标签页，其余标签页由目录监视（内核事件，无轮询）自动更新
- 新增 `--bench <文件夹>` 命令行测速，不打开界面

## v0.2 新增：访达同款功能 + 预览

- **四种显示方式**（每个标签页单独记住）：图标（缩略图网格，状态栏滑块调大小）、列表、分栏（逐级展开，最后一栏显示预览）、画廊（大图预览 + 底部缩略图条 + 详细信息）；⌘1 / ⌘2 / ⌘3 / ⌘4 切换
- **分组与排序**：按名称、种类、修改日期、大小、标签分组（列表和图标视图显示分组标题），同一菜单里切换排序方式和升降序
- **共享**：隔空投送、邮件、信息等系统共享
- **标签**：所有视图里显示访达标签彩点；工具栏标签按钮可给所选文件打 / 去 7 种颜色标签和自定义标签；侧边栏「标签」分区用 Spotlight 列出带该标签的所有文件
- **更多（•••）菜单**：新建文件夹、打开、打开方式、重命名、复制、压缩（zip）、拷贝路径、在访达中显示、显示简介、快速查看、移到废纸篓、显示预览、显示隐藏文件
- **搜索**（⌘F）：输入即按名称过滤当前文件夹；可切换到「包括子文件夹」或「整台 Mac」（Spotlight），结果带位置列；按 Esc 或清除恢复
- **预览面板**（⇧⌘P）：右侧实时预览图片、PDF、视频（可播放）、文本代码、Office 文档等，下方显示种类、大小、日期、图片尺寸、媒体时长、权限，以及打开 / 共享按钮；多选时显示数量和总大小

## 核心功能（v0.1）

- **双栏浏览**：左右两栏各自独立导航，可一键切换单栏 / 双栏；Tab 键在两栏间切换，F5 / F6 拷贝或移动到另一栏
- **多标签页**：每栏都可以开多个标签页，各自有独立的前进 / 后退历史
- **高性能文件列表**：基于 AppKit 原生表格，上万个文件也不卡；名称、修改日期、大小、种类四列，点击表头排序，支持多选和键入名称快速定位
- **路径栏**：面包屑可点击跳转，⌘L / ⇧⌘G 直接输入路径（支持 `~`）
- **显示隐藏文件**：⇧⌘. 一键切换
- **文件操作**：新建文件夹、重命名、拷贝 / 剪切 / 粘贴、制作副本、移到废纸篓；全部支持撤销（⌘Z）。**删除一律进废纸篓，绝不直接永久删除**
- **拖放**：两栏之间、与访达之间都能拖；同一磁盘内默认移动，跨磁盘默认拷贝，按住 Option 强制拷贝
- **右键菜单**：打开、打开方式、快速查看、在访达中显示、拷贝路径、重命名、制作副本、移到废纸篓、显示简介等
- **侧边栏**：个人收藏、自定义书签、最近访问（15 个）、已挂载磁盘及可用空间
- **快速查看**：空格键预览；可选右侧信息面板，显示缩略图、大小、日期、权限、路径
- **空间分析**：递归统计文件夹大小，环形图 + 按大小排序的列表，可逐层下钻，直接在里面定位或移到废纸篓
- **状态栏**：项目数、已选数量及大小、磁盘可用空间
- 记住每栏打开的标签页和路径，浅色 / 深色模式都适配

## 安装

1. 到 [Releases 页面](https://github.com/yostyang/file-butler/releases/latest) 下载 `File-Butler-0.3.dmg`，打开后把「文件管家」拖进「应用程序」。
2. App 为自签名（ad-hoc），首次打开请在「应用程序」里**右键 › 打开**；如果仍提示「无法验证开发者」：打开 **系统设置 › 隐私与安全性**，在页面下方点 **仍要打开**。
   也可以在终端执行：
   ```bash
   xattr -dr com.apple.quarantine /Applications/文件管家.app
   ```
3. 想浏览受保护的系统位置（例如「邮件」「信息」的数据目录），需要在 **系统设置 › 隐私与安全性 › 完全磁盘访问权限** 中打开「文件管家」。

## 从源码构建

需要安装 Xcode（或 Command Line Tools）：

```bash
./build.sh
```

会生成通用版 `build/文件管家.app` 和安装包 `build/文件管家.dmg`。图标由 `swift icon.swift` 生成 `icon.png`，再用 `sips` + `iconutil` 转成 `AppIcon.icns`。

## 测速

```bash
/Applications/文件管家.app/Contents/MacOS/FileButler --bench /某个大文件夹
```

## 自检

```bash
/Applications/文件管家.app/Contents/MacOS/FileButler --selftest
```

只在 `/tmp/fb-test` 里测试新建、重命名、拷贝、移动、废纸篓与撤销、标签、压缩等操作，结束后自动清理。

## 已知限制

- 无法接管桌面，也不能替换系统的打开 / 保存对话框
- 不支持第三方访达扩展（如网盘同步状态图标）
- 列表中文件夹大小显示为「--」，请用空间分析查看

## 权限说明（v0.4 起）
- 应用使用固定的本地签名，系统授予的权限在后续更新后依然有效，不会反复弹窗。
- 首次使用请到「系统设置 › 隐私与安全性 › 完全磁盘访问权限」打开「文件管家」，然后重新打开应用。之后不再需要逐个文件夹授权。

## 与访达一致的操作
- 新建文件夹（⇧⌘N）：未命名文件夹 / 未命名文件夹 2…，创建后直接就地重命名；用所选项目新建文件夹（⌃⌘N）。
- 右键菜单的顺序与访达一致，在 4 种视图和左右两栏中都相同。

## 测试（Testing）
每次改动发布前都必须通过自动化测试，`release.sh` 会先跑 `test.sh`，不通过就不发布。

```bash
./test.sh              # 编译 + 文件操作自测 + 界面测试 + 截图对比
./test.sh --approve    # 人工检查截图后，把本次截图设为新的基准图（Tests/golden/）
./release.sh 0.4.3 "发布说明"   # 测试通过后：改版本、签名、安装、打包、提交、推送、发 GitHub Release
```

- `--selftest`：在 /tmp/fb-test 里测试新建、重命名、拷贝、移动、废纸篓、撤销、标签、替身等文件操作。
- `--uitest <目录>`：应用在自己的进程里启动一个屏幕外的透明窗口（不激活、不抢焦点、不需要辅助功能权限），在 /tmp/fb-ui 沙盒里用合成的鼠标/键盘事件驱动真实界面：四种视图和空文件夹的空白处右键菜单、右键先选中项目、分栏点按文件夹后路径栏、⇧⌘N 新建文件夹 + 就地重命名、回车重命名、⌘C/⌘V、⌘⌫ + ⌘Z、⌘1–4、⌘F 搜索、⇧⌘P 预览、⌥⌘P 路径栏。输出 JUnit 格式的 report.xml 和每一步的截图。测试结束会还原用户设置和剪贴板。
- `--compare <基准目录> <截图目录>`：逐像素对比截图（差异超过 0.5% 判为失败）。
