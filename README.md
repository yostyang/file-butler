# 文件管家（File Butler）

🌐 介绍页：https://yostyang.github.io/file-butler/

一个原生的 macOS 双栏文件管理器，灵感来自 Path Finder。纯 Swift / SwiftUI + AppKit 编写，无第三方依赖，支持 Apple 芯片和 Intel，macOS 13 及以上。

完整版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 主要功能

- **双栏与多标签页**：左右两栏独立导航，可一键切换单栏 / 双栏（`⌥⌘U`）；每栏支持多标签页与独立历史记录，记住上次打开的路径与视图
- **四种显示方式**：图标、列表（AppKit 原生表格，万级文件流畅）、分栏（逐级展开 + 预览）、画廊，支持 `⌘1`–`⌘4` 切换与按名称/种类/日期/大小/标签分组排序
- **与访达一致的文件操作**：新建文件夹（`⇧⌘N`）、用所选项目新建文件夹（`⌃⌘N`）、重命名、拷贝 / 剪切 / 粘贴、制作副本、制作替身、压缩、移到废纸篓；**删除一律进废纸篓，绝不直接永久删除**，全部支持撤销（`⌘Z` / `⌥⌘Z`）
- **进度窗口与冲突处理**：访达式进度窗口（字节进度、剩余时间、多任务排队、可取消不留半截文件）与同名冲突对话框（保留两者 / 停止 / 替换 / 应用到全部）
- **访达式搜索（`⌘F`）**：全盘文件名搜索走 `searchfs(2)` 极速检索，支持搜索建议与历史、Spotlight 按内容全文搜索、多条件筛选行以及保存为侧边栏「已存搜索」
- **效率工具**：命令面板（`⌘K`）、批量重命名（实时预览 + 两步安全改名 + 整批撤销）、跨目录暂存「文件架」、文件夹空间分析（`⌥⌘S`）、右侧实时预览面板（`⇧⌘P`）与空格快速查看

## 安装

1. 到 [Releases 页面](https://github.com/yostyang/file-butler/releases/latest) 下载最新 `.dmg` 安装包，打开后把「文件管家」拖进「应用程序」。
2. 应用目前为本地自签名，首次打开请在「应用程序」里**右键 › 打开**；如果仍提示「无法验证开发者」，可在 **系统设置 › 隐私与安全性** 底部点 **仍要打开**，或在终端执行：
   ```bash
   xattr -dr com.apple.quarantine /Applications/文件管家.app
   ```
3. 首次使用建议在 **系统设置 › 隐私与安全性 › 完全磁盘访问权限** 中开启「文件管家」并重启应用，之后不再需要逐个文件夹授权。

## 从源码构建与测试

需要安装 Xcode（或 Command Line Tools）：

```bash
./build.sh                     # 编译通用版 build/文件管家.app 并打包 build/文件管家.dmg
./test.sh --selftest-only      # 编译 + 文件操作自测（适用于无界面环境 / CI）
./test.sh                      # 完整测试：编译 + 自测 + 界面测试 + 截图对比
./test.sh --approve            # 人工检查截图后更新基准图（Tests/golden/）
```

命令行工具参数：
- `--selftest`：在 `/tmp/fb-test` 里测试文件操作与撤销，结束后自动清理。
- `--uitest <目录>`：在进程内启动屏幕外透明窗口驱动真实界面测试并输出 JUnit 报告与截图。
- `--compare <基准目录> <截图目录>`：逐像素对比截图（差异超过 0.5% 判为失败）。
- `--bench <文件夹>`：大文件夹读取与排序测速，不打开界面。

## 已知限制

- 无法接管桌面，也不能替换系统的打开 / 保存对话框
- 不支持第三方访达扩展（如网盘同步状态图标）
- 列表中文件夹大小显示为「--」，请用空间分析查看
