问题

访达够用，但整理大量文件时总差一点

访达做完了它该做的事。可当你手里有几千个文件要归位时，那"差一点"就会被无限放大——每挪一个文件，都要多切一次窗口。

01 / 少一栏

没有双栏，只能来回切窗口

要把文件从 A 挪到 B，得开两个访达窗口，拖过去，再切回来。文件一多，光找窗口就够烦的。

02 / 多一个 App

想看清磁盘，还得再装一个工具

哪个文件夹最占空间？访达要一个个文件夹去看大小，想一眼看清分布，得另找空间分析软件。

于是有了文件管家。

安全性

放心交给它

文件操作都很保守，出错也能挽回。没有"一键清理"的黑箱，也没有你看不见的后台常驻。

绝不直接删除

删除一律移到废纸篓，不会永久删除。

操作都能撤销

重命名、移动、拷贝、新建、移到废纸篓都可以用 ⌘Z 撤销。

不要管理员密码

不装后台常驻服务，也不改系统文件。

完全开源

所有代码都在 GitHub 上，还自带自检和测速命令。

安装

三十秒装好

没有安装器、没有后台服务，拖进「应用程序」就能用。

  1. 到下载页下载最新的 File-Butler-x.x.dmg。
  2. 打开 DMG，把「文件管家」拖进「应用程序」。
  3. 应用没有经过苹果公证。第一次打开请在「应用程序」里右键 › 打开，或到 系统设置 › 隐私与安全性 点「仍要打开」。也可以在终端运行：
    Terminal
    xattr -dr com.apple.quarantine "/Applications/文件管家.app"
